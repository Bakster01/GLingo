# GLingo · Spotlight 8

Тренажёр английских слов с русским интерфейсом, в стиле Duolingo/Lingo.

**Сайт:** https://bakster01.github.io/GLingo/

- Модуль 1, Socialising: 301 слово и выражение, 55 тренировок.
- Модуль 2, Food & Shopping: 389 слов и выражений, 71 тренировка.
- Всего 690 пар и 1380 заданий на перевод в обе стороны.
- Иллюстрации учебника, произношение, очки опыта, сердечки и повторение.
- Можно выбирать модуль и нужный раздел. Регистрация и подписка не нужны.

Прогресс хранится в `localStorage` текущего браузера, отдельно у каждого посетителя.
Между устройствами он не синхронизируется. Очистка данных сайта удаляет прогресс.
Произношение использует речевой движок браузера и доступные английские голоса.

## Локальный запуск

Нужны Node.js 22.12+ (рекомендуется 24) и pnpm 11.25.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Разработка: http://127.0.0.1:5173/GLingo/

```sh
pnpm test
pnpm build
pnpm preview
```

Просмотр собранного сайта: http://127.0.0.1:4173/GLingo/

## Публикация

GitHub Pages → **Settings → Pages → Source: GitHub Actions**.
Workflow `.github/workflows/pages.yml` проверяет и публикует сайт при изменениях в `main`.
Секреты, аккаунты Clerk, Stripe и серверная база для этой версии не требуются.
Для адреса проекта в `vite.config.ts` установлен `base: '/GLingo/'`.
Маршруты используют hash, поэтому обновление страницы урока работает на Pages.

## Учебный материал и авторство

Словарь перенесён из предоставленного пользователем `spotlight_8-2023.pdf`:
модули 1–2, Word List WL1–WL7 (PDF-страницы 185–191), дополнительная лексика
и иллюстрации страниц 11 и 26. Точные повторы пар в пределах модуля убраны.

- `src/course/spotlight-module1.ts`, `spotlight-module2.ts` — исходные пары и ссылки на страницы.
- `src/course/spotlight-course.ts` — группировка и генерация вариантов.
- `public/spotlight/SOURCE.md` — происхождение иллюстраций.
- `src/lib/progress.ts` — логика личного прогресса.

Интерфейс, кнопки и часть звуков/иллюстраций адаптированы из
[sanidhyy/duolingo-clone](https://github.com/sanidhyy/duolingo-clone) (MIT).
Уведомление об авторстве сохранено в `LICENSE`. Материалы учебника имеют отдельное
происхождение и не объявляются оригинальными материалами авторов GLingo.
